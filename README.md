## التشغيل السريع

افتح المجلد بخادم محلي:

```bash
cd nabeeh
python3 -m http.server 8765
```

ثم زر: http://127.0.0.1:8765

## المميزات

- محادثة ببث مباشر، Markdown، تمييز أكواد، نسخ/إعادة/تعديل
- سجل محادثات في IndexedDB مع بحث وتثبيت وتصدير
- مزودات متوافقة مع OpenAI (OpenAI، OpenRouter، Groq، Gemini، DeepSeek…)
- وضع تجريبي بدون مفتاح
- أدوات كتابة (مقال، بريد، ترجمة، سيرة…) مع لهجة خليجية / فصحى
- إرفاق صور وPDF، إدخال صوتي، قراءة صوتية
- توليد صور (عند ضبط endpoint)، شخصيات وأوامر جاهزة
- قابل للتثبيت (PWA) مع هيكل دون اتصال

## إعداد المفتاح

1. افتح **إعدادات** داخل التطبيق
2. اختر مزوداً جاهزاً أو أدخل Base URL + النموذج
3. الصق مفتاح API — يُحفظ **محلياً في متصفحك فقط**

لا تضع مفاتيح في الكود المصدري أبداً.

## البروكسي الاختياري (VPS)

إذا أردت إبقاء المفتاح على سيرفرك بدلاً من المتصفح:

```bash
cd server
cp .env.example .env   # ضع NABEEH_API_KEY و NABEEH_TARGET_BASE
npm install
npm start              # يستمع على 8791
```

ثم من إعدادات نَبيه فعّل «استخدام بروكسي السيرفر» وعنوان `http://YOUR_VPS:8791`.

البروكسي يمرّر `/v1/chat/completions` و `/v1/images/generations` و `/v1/models` إلى أي API متوافق مع OpenAI، ويضيف المفتاح من البيئة أو من ترويسة `X-Api-Key` المؤقتة.

## الأمان

- المفاتيح في المتصفح تظهر لمن يملك الجهاز — استخدم البروكسي للإنتاج
- لا ترفع ملف `.env` إلى GitHub
